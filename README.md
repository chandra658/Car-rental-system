
# KL DriveNow Car Rental System

A modern car rental web application built with React and Vite.

## Features

- Browse available cars
- Car details and prices
- Login and signup interface
- Car booking system
- Booking management
- Responsive design
- Demo payment feature

## Technologies Used

- React JS
- JavaScript
- CSS
- Vite

## Installation

1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following commands:

```bash
npm install
npm run dev
```

5. Open the localhost link displayed in the terminal.
